# Lingkup single-player setelah audit

Keputusan 23 Oktober 2026 berdasarkan instruksi user: pilih desain paling
sederhana dari GDD dan hasil simulasi. Backend #55–#58 tetap ditahan.

| Sistem di tabel pemangkasan review | Keputusan |
|---|---|
| Rival camp ganda | Sudah dihapus (#21); pertahankan outside offers untuk fighter tidak puas. |
| Banyak angka progres camp | Reputasi dan Prestise menjadi dua sumbu (#38); Legacy/identitas menjadi arsip, tier menunjukkan kapasitas. |
| Pengali training tersembunyi | Relasi dan mentor dihapus (#28/#34); faktor yang tersisa ditampilkan (#42), tanpa menambah pengali. |
| Ambisi fighter | Pertahankan yang sudah mendapat efek nyata (#26). |
| Negosiasi | Empat tuas: signing bonus, bagian camp, jumlah laga, durasi. Tidak ada equity baru; klausul lama tanpa efek sudah dibuang (#27). |
| Equity dan investor | Hentikan penawaran equity baru. Kontrak tersimpan tetap dibayar; semua potongan masuk preview pengeluaran bersama. Event kemakmuran tidak lagi menjanjikan investasi yang tidak bisa diterima. |
| Relasi promotor per tier | Pertahankan lima relasi: langsung mengatur purse/main event/eliminator dan memberi pilihan tier yang nyata. Penjelasan UI diperbaiki (#48). |
| Kepribadian promotor | Pertahankan efek purse yang sudah diuji (#35), bukan sistem AI camp baru. |
| Cutman/Nutritionist | Pertahankan karena sudah mengurangi cut dan penalti weight cut (#6/#30). |
| Museum kosmetik | Hapus dari daftar pembelian. Flag kepemilikan lama tetap tersimpan; tidak ada refund/reset progres. |
| Pinjaman | Tidak ditambahkan (#33/#39). Pemulihan memakai kas, payroll dan fasilitas nyata. |
| Panel debug ekonomi | Hapus dari layar pemain. Rumus pemasukan/pengeluaran bersama dan tes tetap dipertahankan. |
| Dokumen lama | Arsipkan dengan indeks sejarah (#62). |
| Backend | Pertahankan source; pengembangannya ditunda sesuai user. |

Fight engine, Fight Night, scouting, cedera, aging, dan ranking dipertahankan.
Keputusan ini sudah diperiksa lewat tes, browser dan simulasi; sesi manual
beberapa jam oleh playtester manusia masih diperlukan untuk menilai rasa pacing
dan kebosanan, bukan alasan mengklaim balance sudah sempurna.
