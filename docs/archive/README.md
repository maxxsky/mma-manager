pernah menilai sistem dari keberadaan kode; kesimpulannya tidak boleh menggantikan
tes perilaku dan pengukuran Oktober.

`CONSTRAINTS.md`, `PROJECT_CONSTITUTION.md`, standar engineering dan prosedur kerja
tetap berada di lokasi aktif. Seluruh `docs/balance/` dipertahankan sebagai riwayat
pengukuran. Spesifikasi championship/promotion tetap di `design/`; discovery
championship lama menunjuk ke arsip.

File arsip dapat mengandung path atau tautan yang berlaku saat dibuat. Gunakan
sumber aktif di atas untuk struktur, angka balance dan keputusan lingkup sekarang.
